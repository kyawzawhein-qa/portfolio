# QA Engineer Portfolio (Next.js + Prisma + NextAuth)

Single-page dynamic portfolio with a secure admin panel.

## Features

- Public portfolio page at `/` with data from Prisma (SQLite)
- Admin login at `/login` (NextAuth Credentials)
- Protected admin dashboard at `/admin`
- Server Actions for creating/updating Profile, Experience, Education, and Skill
- Seed script with initial QA Engineer data

## Default Admin Login

- Email: `admin@example.com`
- Password: `admin123`

Change them in `.env` before production use.
